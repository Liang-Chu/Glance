# Notification Tip

An Android app that posts short notifications which clear themselves, so they can be carried to Even
G2 glasses by the glasses' own notification feature.

## What it does

*Aspirational: this section describes the intended product. What is actually built is
[`docs/STATUS.md`](docs/STATUS.md).*

- Posts concise notifications on Android and takes them away again without anyone dismissing them.
- Reaches the glasses through the G2's existing notification feature rather than talking to the
  glasses directly.
